アクアスブラー  
製作者：Panko200  
配布場所：https://github.com/panko200/AqueousBlur

## 概要

CC Vector Blurをまねようとしたらよくわからんくなったものです。

## 使用方法

映像エフェクト「アクアスブラー」が追加されます。  
あんまりよくわかりません。なんかきもいので、陽炎ブラーのほうが楽しいです。

## アンインストール方法

1. YMM4 を起動して`ヘルプ(H)`>`その他`>`プラグインフォルダを開く`をクリックする。
2. YMM4 を終了する。
3. `AqueousBlur`という名前のフォルダを削除する。

## 注意点

ゆっくりムービーメーカーv4.50.0.3で動作を確認しています。
